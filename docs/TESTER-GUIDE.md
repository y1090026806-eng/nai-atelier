# NAI Atelier 测试版使用说明（v1.7.0）

> **这是什么**：一个本地运行的「自然语言 → 英文 Danbooru Tags → NovelAI 生图 → 本地画廊」网页工作台。
> 所有数据都在你自己的电脑上，不需要注册，也没有服务器端。
> **请勿外传**：这是私下分享的测试版，安装包和源码都不要转发、上传网盘或公开。

---

## 0. 最快开始（30 秒）

已经装好 Node.js 的话：

```bash
npm ci
npm start
```

浏览器打开 <http://127.0.0.1:3000>。

---

## 1. 环境要求

| 项 | 要求 |
| --- | --- |
| Node.js | **18.17 或更高**，推荐 20 / 22 LTS：<https://nodejs.org/zh-cn> |
| 系统 | Windows 10/11、macOS 12+、Linux 都可以（主要在 Windows 上测试过） |
| 磁盘 | 程序约 10 MB；生成的图片每张 1–3 MB，自己留意空间 |
| 账号 | 需要你自己的 LLM API Key（DeepSeek 等）和 NovelAI 订阅 / Token |

> 测试生成会消耗**你自己的** NovelAI Anlas / LLM 额度。没有 NovelAI 账号也可以先做第 3 节的自检和界面测试。

## 2. 安装与启动

> 你拿到的可能是两种包之一：
> - **`*-offline.zip`**：已经带了依赖，解压后直接启动，不需要联网装依赖；
> - **`*-src.zip`**：不含依赖，首次需要 `npm ci`（要能访问 npm 源）。
> 两者都仍然需要本机装好 Node.js。

### Windows（推荐）

1. 把压缩包解压到**不含中文、不含空格**的路径，例如 `D:\nai-atelier`。
2. 双击 **`start-windows.bat`**。
   - 第一次会自动安装依赖（约 5 MB），然后启动服务并打开浏览器。
   - 如果压缩包里已经带了 `node_modules`，会直接启动，不需要联网。
3. 以后每次双击 `start-windows.bat` 即可；也可以双击原来的 `start-nai-atelier.bat`（它不会自动装依赖）。

如果提示「未检测到 Node.js」：先去 <https://nodejs.org/zh-cn> 下载 LTS 安装包，安装时保持默认选项（会自动加入 PATH），然后重新双击。

### macOS / Linux

```bash
cd nai-atelier-1.7.0
bash start.sh
```

或者手动：

```bash
npm ci
npm start
```

### 通过 GitHub 获取（不需要账号）

仓库是公开的，任何人都不用登录、不用权限即可克隆：

```bash
git clone https://github.com/y1090026806-eng/nai-atelier.git
cd nai-atelier
npm ci
npm start
```

以后更新只需要 `git pull`。想贡献代码可以 Fork 后提 PR；直接 clone 的副本不会被误推到上游。

### 依赖安装失败

国内网络可以换镜像后重试：

```bash
npm config set registry https://registry.npmmirror.com
npm ci
```

仍然失败时，直接使用带 `node_modules` 的离线包（`*-offline.zip`），解压后不需要执行 `npm ci`。

## 3. 先做一次「不花钱」的自检

```bash
npm run verify
```

- 共 **235 项**检查，使用本地假 LLM / 假 NovelAI 和临时目录；
- **不联网、不消耗额度、不碰你的数据**，大约 30 秒；
- 看到 `235/235 通过` 就说明环境没问题，可以继续配置 Key。

---

## 4. 首次配置（网页左侧栏）

1. **LLM**
   - Base URL：例如 `https://api.deepseek.com/v1`（末尾带 `/v1`）；
   - API Key：你自己的 Key；
   - 模型：点「拉取模型」选择，或手动输入（如 `deepseek-chat`）；
   - 温度 / 最大 Token 用默认即可；
   - 点保存。
2. **NovelAI**
   - API Key：NovelAI 的 Persistent Token；
   - 模型、采样步数、宽高、负面提示词按需；
   - 点保存。
3. **提示词结构**：默认已有一段 System 提示词，可改；改完保存。
4. 底部输入框写画面描述（中文可以），点 **Generate**。

> Key 会以明文保存在本机 `data/config.json`，只存在你自己的电脑上；不要把这个文件发给任何人。

## 6. 已知限制（测试版）

- **只适合本机使用**：默认监听 `127.0.0.1`，没有登录 / 鉴权。不要改成 `0.0.0.0`，不要放到公网或公司内网。
- 单并发队列：同一时间只跑一个生成任务。
- macOS / Linux 未做完整实机测试；Windows 是主要目标。
- 没有自动更新；新版本需要手动替换文件（保留 `data/` 与 `outputs/`）。
- 生成失败优先检查 Key、订阅额度、网络；报错在页面 toast 和服务端窗口里。

## 7. 出问题怎么反馈

请尽量提供：

1. 页面右上角的版本号（应为 `v1.7`）；
2. 操作系统 + 浏览器版本；
3. 复现步骤：点了什么、期望什么、实际什么；
4. 浏览器 F12 → Console 的报错截图；
5. 服务端窗口最后 20 行日志。

**不要发送 `data/config.json`**（里面有明文 Key）。如果必须提供配置内容，请先把 Key 替换成 `sk-***`。

---

## 8. 升级与卸载

- **升级**：先备份，再保留 `data/` 和 `outputs/` 两个目录，用新版本的其他文件覆盖；或直接解压新包后把旧 `data/`、`outputs/` 复制回去。
- **卸载**：删除整个安装目录即可，不会在系统里留下服务。

## 9. 常见问题

| 现象 | 处理 |
| --- | --- |
| 端口 3000 被占用 | Windows：`set PORT=3100 && npm start`；macOS/Linux：`PORT=3100 npm start`，然后访问 `http://127.0.0.1:3100` |
| 页面还是旧版本 | `Ctrl + F5` 强制刷新（程序对静态资源做了 no-store，一般普通刷新即可） |
| 「拉取模型」失败 | Base URL 要带 `/v1`；Key 有效；网络能访问该服务商 |
| 生成返回 401 / 402 | NovelAI Token 或订阅额度问题；先确认能在官网正常生成 |
| `npm` 不是内部或外部命令 | Node 安装时没加入 PATH，重装并勾选默认选项 |
| 路径含中文 / 空格导致异常 | 换到 `D:\nai-atelier` 这类纯英文路径 |
| 杀毒软件拦截 | 本地 Node 服务可能被误报；确认来源可信后放行 |
